# Getting help

| You want | Go to |
|---|---|
| Run it in 3 commands | [`README.md`](README.md) quickstart |
| Understand a design decision | [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/FEATURE-CONTRACTS.md`](docs/FEATURE-CONTRACTS.md) |
| Harden a deployment | [`docs/SECURITY.md`](docs/SECURITY.md), `python -m yantraops audit-security` |
| Diagnose a broken install | `python -m yantraops doctor` |
| Report a bug / request a feature | a [GitHub issue](https://github.com/CD-LC/yantrafleet/issues/new/choose) |
| Challenge a VDA 5050 conformance verdict | the *VDA 5050 conformance question* issue form (cite the clause) |
| Report a **vulnerability** | [private advisory](https://github.com/CD-LC/yantrafleet/security/advisories/new) - never a public issue ([`SECURITY.md`](SECURITY.md)) |

When you ask, include the version, the component, the exact command, and logs
with keys, tokens and webhook URLs **redacted**. This is community support:
there is no SLA, and commercial support is not offered from this repository.
